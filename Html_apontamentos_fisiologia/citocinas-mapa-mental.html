IL-1α / IL-1β — O Detonador da Inflamação ▶
Estrutura e Produção
Família β-trefoil (folhas beta em trevo) • 17 kDa (madura) • IL-1α constitutiva; IL-1β induzível
Produtores: macrófagos, monócitos, células dendríticas, células epiteliais, fibroblastos
Mecanismo de Ativação — 2 Sinais Obrigatórios
Sinal 1 (Priming): LPS → TLR4 → MyD88 → IRAK4 → TRAF6 → IKK → IκB fosforilado → degradação pelo proteassoma → NF-κB livre → núcleo → transcrição de pró-IL-1β (31 kDa, inativa) LPS–LBP → CD14 → TLR4/MD2 → MyD88 → IRAK4 → TRAF6 → TAK1 → IKKβ → p-IκBα → Ub → proteassoma → NF-κB(p65/p50) → promotor IL1B
Sinal 2 (Inflamassoma NLRP3): ATP/cristais MSU/silício → K+ efflux → NLRP3 oligomeriza → recruta ASC (domínio PYD-PYD) → ASC recruta pró-caspase-1 (domínio CARD-CARD) → caspase-1 ativa (p10+p20) → cliva pró-IL-1β → IL-1β madura (17 kDa) → secreção via gasdermin D (GSDMD) Cristal MSU → lisossomo → catepsinas → K⁺ efflux → NLRP3↑ → ASC speck → caspase-1 → pró-IL-1β(31kDa) → IL-1β(17kDa) + GSDMD poros → piroptose
Receptor e Sinalização
IL-1R1 (receptor funcional) + IL-1RAcP (proteína acessória) → domínios TIR citoplasmáticos → MyD88 → IRAK4 → IRAK1 → TRAF6 → TAK1 → NF-κB + MAPK (p38, JNK) IL-1β+IL-1R1+IL-1RAcP → TIR:TIR → MyD88:IRAK4 → K63-Ub:TRAF6 → TAB2/3:TAK1 → IKK → NF-κB + AP-1
IL-1R2 = decoy receptor (sem domínio TIR → sem sinalização → sequestra IL-1 → regulação negativa)
Efeitos Fisiológicos (Mecanismo)
Febre: IL-1β → hipotálamo (OVLT) → COX-2 → PGE2 → receptor EP3 → ↑AMPc → ↑ponto de ajuste temperatura IL-1β → endotélio OVLT → NF-κB → COX-2 → AA → PGE2 → EP3-R em neurônios termorregulatórios → AMPc↑ → PKA → set point↑
Fase aguda: IL-1β → hepatócito → NF-κB/STAT3 → ↑PCR, fibrinogênio, SAA, haptoglobina, ceruloplasmina; ↓albumina, transferrina (proteínas negativas de fase aguda)
Destruição articular: IL-1β → sinoviócitos tipo B → ↑MMP-1/3/13 → digestão colágeno/proteoglicanos; ↑RANKL → RANK em osteoclastos precursores → NFATc1 → osteoclastogênese → erosão óssea
Comportamento doentio: IL-1β → prostaglandinas no SNC → ↓motivação, anorexia, hipersonia, ↓atividade locomotora (via receptores em hipocampo e hipotálamo)
Farmacologia Anti-IL-1
Anakinra: IL-1Ra recombinante humana → compete com IL-1α/β pelo IL-1R1 → sem sinalização ARGota refratáriaStillSAM
Canakinumabe: IgG1κ totalmente humano anti-IL-1β → alta afinidade, meia-vida ~26 dias Gota crônicaFMFCAPSPericardite recorrente
Rilonacept: proteína de fusão IL-1R1-IL-1RAcP-Fc → captura IL-1α e IL-1β e IL-1Ra
Colchicina: inibe polimerização de tubulina → ↓montagem do inflamassoma NLRP3 (precisa de microtúbulos) + ↓migração neutrofílica Colchicina + β-tubulina → sequestra dímeros → sem polimerização → ↓speck ASC → ↓caspase-1 → ↓IL-1β
IL-2 — A Citocina da Vida Linfocitária ▶
Estrutura
133 aa, ~15 kDa, feixe de 4 α-hélices. Produzida principalmente por linfócitos T CD4+ ativados
Receptor Trimérico e Afinidade
IL-2Rα (CD25) — cadeia α, Kd ~10 nM; expressão induzida por TCR + CD28; específica para IL-2
IL-2Rβ (CD122) — cadeia β, compartilhada com IL-15R; Kd ~1 µM isolada
IL-2Rγc (CD132) — cadeia γ comum; compartilhada por IL-4R, IL-7R, IL-9R, IL-15R, IL-21R → mutação → SCID-X1
Trímero αβγ = alta afinidade Kd ~10 pM → ativação em concentrações picomolares
Via de Sinalização Detalhada
JAK1 (associada a IL-2Rβ) + JAK3 (associada a γc) → transautofosforilação recíproca → fosforilam Y-364/Y-392 do IL-2Rβ → STAT5a/b recruta (domínio SH2) → STAT5 fosforilado (pY694) → dimeriza → núcleo → GAS → ↑Bcl-2, ↑Bcl-xL (sobrevida), ↑ciclina D → proliferação IL-2 → IL-2Rαβγ → JAK1(β):JAK3(γ) → pY-receptor → STAT5 SH2:pY → pSTAT5 dímero → GAS(5'TTCNNNGAA'3) → Bcl-2↑, Cis↑, Id2↑
Via PI3K/Akt: IL-2Rβ → IRS-1/2 → PI3K → PIP3 → Akt → mTORC1 → síntese proteica, crescimento celular
Via MAPK/Ras: IL-2Rβ → Shc → Grb2 → SOS → Ras → Raf → MEK → ERK1/2 → proliferação e diferenciação
Funções Fisiológicas
Proliferação clonal: ↑IL-2Rα (CD25) após ativação → loop autócrino → expansão clonal T (até 10⁴–10⁵× em infecção aguda)
Tregs: FoxP3 → ↑expressão constitutiva CD25 → alta sensibilidade à IL-2 → sobrevida e supressão. Sem IL-2 → Tregs morrem → autoimunidade
AICD (Activation-Induced Cell Death) — altas doses IL-2 → ↑Fas/FasL → apoptose → homeostase linfocitária
Farmacologia
Ciclosporina/Tacrolimus: bloqueiam calcineurina → NFAT permanece fosforilado → fica no citoplasma → ↓transcrição IL2 → imunossupressão pós-transplante TCR→Ca²⁺→calmodulina→calcineurina→desfosforila NFAT→núcleo→IL2. CsA:ciclofilina ou FK506:FKBP12 → inibe calcineurina → NFAT preso citoplasma
Basiliximabe/Daclizumabe: anti-CD25 → bloqueia IL-2Rα → ↓proliferação T no enxerto (indução de imunossupressão no transplante renal)
Aldeslequina (IL-2 recombinante alta dose) → melanoma/carcinoma renal metastático → risco: síndrome de extravasamento capilar (IL-2 → ↑permeabilidade endotelial via ↓VE-caderina)
IL-4 / IL-13 — Eixo da Atopia e Tipo 2 ▶
Produção e Estrutura
IL-4: 129 aa, 15–19 kDa. Produzida por Th2, mastócitos, basófilos, NKT, ILC2
IL-13: 132 aa, 12 kDa. Produzida por Th2, ILC2, mastócitos, NKT, eosinófilos
Receptores e Sinalização
Tipo I (linfócitos): IL-4Rα + γc → JAK1 (IL-4Rα) + JAK3 (γc) → IRS-1/2 → PI3K/Akt + pSTAT6 → STAT6 dímero → STAT6-RE → ↑GATA-3 (fator mestre Th2), ↑IL-4, ↑IL-5, ↑IL-13 IL-4 → IL-4Rα:γc → JAK1:JAK3 → pY-receptores → STAT6(SH2:pY) → pSTAT6 dímero → 5'TTCNNNNGAA'3 → GATA-3↑
Tipo II (células não hematopoiéticas): IL-4Rα + IL-13Rα1 → JAK1 (IL-4Rα) + TYK2 (IL-13Rα1) → STAT6 → resposta em pulmão, pele, intestino. IL-13 liga principalmente esse receptor tipo II
Efeitos Celulares (Mecanismo)
Switching IgE: IL-4/IL-13 → células B → STAT6 → fator ε-germline transcript → AID (Activation-Induced Cytidine Deaminase) → recombinação de classe Cµ→Cε → plasmócitos produtores de IgE IL-4+IL-13 → pSTAT6 → εGLT transcrição → AID → switch rec. → VDJ:Cε → IgE
Macrófago M2 alternativo: IL-4/IL-13 → STAT6 → ↑Arginase-1 (compete com iNOS → menos NO → menos kill) + ↑CD206 (manose-R) + ↑TGF-β + ↑IL-10 → remodelamento, fibrose, tolerância
Hipersecreção de muco (IL-13 dominante): IL-13 → células caliciformes e Club cells → SPDEF → ↑MUC5AC, ↑MUC5B → obstrução brônquica
Hiperresponsividade brônquica (IL-13): músculo liso → ↑Ca²⁺ intracelular via ROCK → contração → broncoespasmo; ↑VEGF → remodelamento vascular
Eosinofilia (IL-5 induzida por IL-4): GATA-3 induz IL-5 → eosinófilos na mucosa

IL-6 — A Maestrina da Fase Aguda ▶
Estrutura e Trans-Signaling
184 aa, 21–28 kDa (variável por glicosilação). Feixe 4 α-hélices. Produção ubíqua.
Sinalização clássica (cis): IL-6 → IL-6R (gp80) + gp130 → homodimerização gp130 → JAK1 (gp130) + JAK2/TYK2 → STAT3 → ↑PCR, ↑fibrinogênio, ↑haptoglobina. Apenas hepatócitos, macrófagos, neutrófilos e células T expressam IL-6R membrana
Trans-signaling: ADAM10/17 → shedding de IL-6R → sIL-6R solúvel → IL-6+sIL-6R se complexam → ligam gp130 (ubíqua em TODAS células) → JAK/STAT3 em células que normalmente não respondem à IL-6. Amplifica drasticamente os efeitos sistêmicos ADAM17 → ectodomínio IL-6R → sIL-6R(55kDa) → IL-6:sIL-6R complexo → gp130:gp130 → JAK1:TYK2 → pY757-gp130 → STAT3 SH2 → pSTAT3 → APRE(acute-phase response element)
Via JAK-STAT3 na Fase Aguda (Mecanismo Detalhado)
No hepatócito: pSTAT3 → sítios APRE/GAS nos promotores → ↑transcrição: PCR (↑1000×), fibrinogênio (↑3×), SAA (↑1000×), haptoglobina (↑5×), ferritina, α1-antitripsina; ↓ albumina, transferrina (regulação inversa via SOCS3 inibindo STAT3 basal) STAT3:APRE → C/EBPβ cooperação → RNA polII → PCR mRNA (t½ ~30h) → PCR: pentraxina pentamérica → opsonização, ativação complemento clássico
Hepcidina: IL-6 → hepatócito → STAT3 → ↑HAMP (gene hepcidina) → hepcidina → liga ferroportina (FPN1/SLC40A1) → ubiquitinação → internalização → degradação → Fe preso em macrófagos/enterócitos → ↓sideremia → anemia de doença crônica
Bloqueio de IL-6 — Farmacologia
Tocilizumabe (anti-IL-6R humanizado, IgG1): bloqueia IL-6R membrana E sIL-6R → bloqueia cis- E trans-signaling. IV q4sem ou SC q2sem ARAIJsCOVID-19 graveSLC pós-CAR-TCastleman
Atenção: após tocilizumabe, IL-6 sérica sobe paradoxalmente (receptor bloqueado → IL-6 não é degradada pelo receptor → acumula). Usar PCR e ferritina como marcadores de resposta, NÃO IL-6 sérica
Sarilumabe: anti-IL-6Rα humano. Alta afinidade. SC q2sem. AR.
Siltuximabe: anti-IL-6 direto (não anti-receptor). IV. Doença de Castleman multicêntrica idiopática.
IL-10 — A Guardiã da Tolerância ▶
178 aa, 18–19 kDa, homodímero antiparalelo. Família IL-10: IL-10, IL-19, IL-20, IL-22, IL-24, IL-26, IFN-λ
Receptor: IL-10Rα + IL-10Rβ → JAK1 (IL-10Rα) + TYK2 (IL-10Rβ) → STAT3 → SOCS3 → apaga a própria sinalização (feedback) + ↑IL-10 (auto-amplificação) IL-10:IL-10Rα:IL-10Rβ → JAK1:TYK2 → pY446-IL-10Rα → STAT3(SH2) → pSTAT3(Y705) → STAT3RE → SOCS3↑ (apaga JAK) + STAT3→IL10↑ (loop)
Mecanismo supressor no macrófago: pSTAT3 → ↓NF-κB (bloqueia transcrição de TNF, IL-1, IL-6, IL-12, IL-18) + ↓HLA-DR (↓apresentação de Ag) + ↓CD80/86 (↓coestimulação) → macrófago tolerogênico pSTAT3 → Bcl-3 (inibe NF-κB:DNA) → ↓IL6/TNF/IL12 mRNA + ↓CIITA → ↓HLA-DR

IL-17 — Recrutamento de Neutrófilos ▶
Família: IL-17A (mais estudada), IL-17F; heterodímero IL-17AF. Homodímeros. Produtores: Th17, γδ T, ILC3, neutrófilos, mastócitos
Receptor: IL-17RA + IL-17RC (heterodímero) → domínio SEFIR intracelular → Act1 (adaptador, domínio SEFIR:SEFIR) → K63-ubiquitina → TRAF6 → TAK1 → IKK → NF-κB + C/EBPβ + C/EBPδ → quimiocinas e peptídeos antimicrobianos IL-17A:IL-17RA:IL-17RC → SEFIR:Act1(K63-Ub-TRAF6) → TAK1 → NF-κB(p65) + C/EBPβ → CXCL8/CXCL1/CXCL5/CXCL6 → neutrófilos + hBD-2/hBD-3/S100A8/S100A9

IL-18 — Amplificador de IFN-γ e SAM ▶
193 aa, 24 kDa (pró) → 18 kDa (madura). Processamento por caspase-1 (inflamassoma NLRP3/NLRP1) ou caspase-4/5/11 (caspases não-canônicas → piroptose)
Receptor: IL-18Rα + IL-18Rβ → MyD88 → IRAK4/1 → TRAF6 → NF-κB + MAPK (idêntico à IL-1R!)
Sinergia com IL-12: IL-12 → ↑IL-18Rβ em células NK/T → maior sensibilidade a IL-18 → sinergismo → IFN-γ máximo. Sem IL-12, IL-18 sozinha é fraca indutora de IFN-γ
Regulação por IL-18BP: IL-18 Binding Protein = proteína endógena secretada que sequestra IL-18 com alta afinidade (Kd ~400 pM) → regulação negativa. Tadekinig alfa = IL-18BP recombinante (investigacional em SAM)
Biomarcador SAM/LHH: IL-18 >10.000 pg/mL; razão IL-18/CXCL9 >24,9 → diagnóstico de SAM vs. outras causas de hiperferritinemia

TNF — FATOR DE NECROSE TUMORAL
TNF-α / LTα / TRAIL / FasL
▶
Estrutura e Biossíntese ▶
Homotrímero, cada subunidade 17 kDa (sTNF) ou 26 kDa (tmTNF). Estrutura β-jelly roll com simetria C3
Biossíntese regulada em 3 níveis: 1. Transcricional: NF-κB → promotor TNF 2. Pós-transcricional: ARE (AUUUA)5 na 3'UTR → TTP (Tristetraprolin) → decaimento mRNA; HuR estabiliza em hipóxia 3. Traducional: proteína 40S subunit ribossomal → regulação seletiva 4. Pós-traducional: tmTNF → TACE/ADAM17 → sTNF (shed)
Forma transmembrana (tmTNF): sinalização bidirecional — inside-out signaling: célula que expressa tmTNF pode receber sinal reverso quando seu tmTNF se liga a TNFR2 (ativa NF-κB no produtor de TNF)
TNFR1 vs TNFR2 — Sinalização Divergente ▶
TNFR1 (p55/CD120a): domínio DD (Death Domain) → recrutamento de TRADD: TNF trímero → TNFR1 trimeriza → TRADD(DD:DD) → bifurcação: Via 1: TRADD → FADD(DD:DD) → pró-caspase-8 → DISC → caspase-8 ativa → caspase-3 → APOPTOSE Via 2: TRADD → TRAF2 → RIP1 → K63-Ub → TAK1 → IKK → NF-κB → sobrevida (Bcl-xL, FLIP, c-IAP) = BLOQUEIA VIA 1
TNFR2 (p75/CD120b): sem domínio DD → sinaliza via TRAF1/TRAF2 → NF-κB + PI3K/Akt → sobrevida, proliferação, Tregs. Alta afinidade por tmTNF. Expresso em células imunes, endotélio, neurônios
O paradoxo TNF: em células com NF-κB ativo → sobrevida predomina; em células com NF-κB bloqueado (ou com Smac/DIABLO liberado → inibe IAPs) → apoptose predomina. Base da seletividade anti-tumoral do TNF
Efeitos Sistêmicos do TNF (Mecanismo por Órgão) ▶
Endotélio vascular: TNF → NF-κB → ↑E-selectina (leucocyte rolling), ↑ICAM-1/VCAM-1 (firm adhesion) + ↑PAF + ↑COX-2 → PGI2 (vasodilatação) + ↑TF (fator tecidual → inicia coagulação extrínseca) + ↓trombomodulina (pró-trombótico) → DIC
Hipotálamo: PGE2 via COX-2 → ↑set point → febre (sinérgico com IL-1β e IL-6)
Caquexia (adiposo + músculo): TNF → ↑lipase hormônio-sensível (lipolisis) + ↑ubiquitina-proteasoma (↑Atrogin-1/MuRF-1) → proteólise muscular + ↓síntese. TNF historicamente chamado de caquetina
Sinovial: TNF → sinoviócitos → ↑MMP-1/3/13 + ↑RANKL → erosão cartilagem e osso. O TNF é o "maestro" da AR — bloquear TNF é suficiente para parar a progressão articular
Choque séptico: doses altas de sTNF → ↑NO sistêmico (iNOS endotelial/macrófagos) → vasodilatação generalizada → hipotensão refratária → choque distributivo
Anti-TNF — Mecanismos Distintos (Tabela Comparativa) ▶
Infliximabe (quimérico 25% murino/75% humano): liga sTNF + tmTNF → induz ADCC + CDC + apoptose de células tmTNF+. Por isso funciona em Crohn fistulizante (destrói células inflamatórias que expressam tmTNF)
Adalimumabe (humano): mesmos mecanismos do infliximabe, SC. Menor imunogenicidade que infliximabe
Certolizumabe: Fab' sem Fc → sem ADCC/CDC → só neutralização. Sem Fc → não cruza placenta via FcRn → seguro na gestação. Distribuição no SNC menor (Fc media passagem em SNC)
Etanercepte (TNFR2-Fc): receptor solúvel → neutraliza sTNF (não induz apoptose de tmTNF+) → NÃO funciona em Crohn. Preferencial para TNFR2 → não neutraliza LTα (que usa TNFR1/2). Meia-vida mais curta
Imunogenicidade: anti-drug antibodies (ADA) reduzem eficácia → adicionar metotrexato (imunossupressor) diminui ADA especialmente com infliximabe e adalimumabe (não necessário com etanercepte)

INTERFERONS (IFN)
Tipo I / II / III
▶
IFN Tipo I — Defesa Antiviral Sistêmica ▶
Indução
Detecção de ácidos nucleicos virais: dsRNA citosólico → RIG-I/MDA5 (helicases) → CARD:CARD → MAVS (mitocôndria) → TBK1/IKKε → IRF3/IRF7 fosforilados → dimerizam → núcleo → promotores IFNB1 + IFNA ssRNA endossomal → TLR7/8 → MyD88 → IRAK4 → TRAF6 → IRF7 → IFN-α dsDNA citosólico → cGAS → cGAMP → STING → TBK1 → IRF3 → IFN-β
Sinalização — Via JAK-STAT ISGF3
IFNAR1+IFNAR2 → JAK1(IFNAR2)+TYK2(IFNAR1) → pY466-IFNAR1 + pY457-IFNAR2 → STAT1+STAT2 recrutam → pSTAT1:pSTAT2 → associam IRF9 → ISGF3 → ISRE (5'GAAA(N)₂GAAA'3) → ISGs pSTAT1:STAT2:IRF9 = ISGF3 → ISRE → OAS1/2/3, PKR(EIF2AK2), Mx1/Mx2, IFIT1/2/3, ISG15, TRIM25, APOBEC3G, tetherin(BST2), viperin
Mecanismos ISGs (Detalhado)
OAS+RNAse L: OAS sintetiza 2'–5' oligoadenilato → ativa RNAse L latente → degrada RNA viral (e celular!) → bloqueio de síntese proteica viral
PKR (EIF2AK2): detecta dsRNA → autofosforila → fosforila eIF2α(Ser51) → bloqueia iniciação traducional → síntese proteica global cai → célula "paralisa" → cria estado antiviral
Mx1: GTPase dynamin-like → auto-oligomeriza em anéis → envolve nucleocapsídeos virais → sequestra/degrada → eficaz contra influenza, VSV, bunyavírus
TRIM5α: F-box E3 ubiquitin ligase → reconhece cápside retroviral → poliubiquitina → proteassoma → bloqueia integração retroviral. Específico de espécie (humano TRIM5α não bloqueia HIV eficientemente)
APOBEC3G/H: citidina desaminase → incorporada em virions → desamina dC→dU no DNA viral recém-sintetizado → hipermutação G→A → genoma viral inviável. HIV contornou com Vif que degrada APOBEC3G
Farmacologia IFN Tipo I
IFN-β1a/1b (Avonex®, Rebif®, Betaferon®): esclerose múltipla → ↑IL-10 + ↑TGF-β + ↓MHC II em APCs + ↓migração linfocitária pelo SNC (↑ICAMsol, ↓VCAM1 na BHE)
IFN-α (PEGilado): hepatite B/C crônica (substituído por DAAs), leucemia mieloide crônica (substituído por imatinibe), melanoma (substituído por checkpoint inhibitors), leucemia de células pilosas
Anifrolumabe (anti-IFNAR1): bloqueia IFN tipo I → LES refratário (assinatura IFN alta no LES ativo)
IFN-γ (Tipo II) — Ativação Macrofágica M1 ▶
Homodímero, 143 aa/subunidade, ~17 kDa/subunidade. Produzido por NK (inata rápida) + Th1 + CD8+ (adaptativa)
Receptor: IFNGR1(cadeia α, ligação) + IFNGR2(cadeia β, sinalização) → JAK1(IFNGR1)+JAK2(IFNGR2) → pY440-IFNGR1 → STAT1 SH2:pY → pSTAT1:pSTAT1 homodímero (GAF) → GAS(5'TTCNNNNGAA'3) → ISGs + genes ativação M1 IFN-γ dímero → IFNGR1:IFNGR2 → JAK1:JAK2 transativar → pY440:pY440-IFNGR1 → STAT1 recrutado → pSTAT1(Y701) → GAF → GAS → CIITA(↑MHC II), iNOS(↑NO), IRF1(→ISGs), IDO1, CXCL9/10/11
Ativação clássica M1 (mecanismo molecular): IFN-γ → STAT1:GAF → IRF1 → iNOS → L-arginina → NO + L-citrulina → ·NO + O₂⁻ (NADPH oxidase) → ONOO⁻ (peroxinitrito) → dano oxidativo intracelular → matar micobactéria/Leishmania
↑MHC II via CIITA: IFN-γ → STAT1 → IRF1 → CIITA (master regulator MHC II) → ↑expressão HLA-DR/DP/DQ em macrófagos, DCs, células endoteliais, epiteliais → melhor apresentação antigênica
IDO (Indoleamine 2,3-dioxygenase): IFN-γ → STAT1 → IDO1 → degrada triptofano → ↓Trp → ativação de GCN2 em células T → ↓proliferação T (supressor local). Mecanismo de imuno-evasão tumoral e tolerância materno-fetal
Emapalumabe (anti-IFN-γ): LHH primária refratária/recidivante → bloqueia ativação macrofágica incontrolável
MSMD: deficiência IFNGR1/2 ou STAT1 → infecções por micobactérias não-tuberculosas e BCGose após vacinação → via DO IFN-γ essencial para imunidade intracelular
IFN Tipo III (IFN-λ) — Proteção Epitelial ▶
IFN-λ1 (IL-29), IFN-λ2 (IL-28A), IFN-λ3 (IL-28B). Receptor: IFNLR1 (=IL-28Rα) + IL-10Rβ → JAK1+TYK2 → ISGF3 (idêntico ao tipo I) → mesmos ISGs
Distribuição do receptor: IFNLR1 expresso quase exclusivamente em células epiteliais (pulmão, intestino, fígado, pele). Portanto: mesma potência antiviral que IFN tipo I em epitélios, mas sem efeitos sistêmicos (febre, mielossupressão)
Farmacogenômica IL28B: SNP rs12979860 (C→T): genótipo CC → maior produção de IFN-λ3 → clearance espontâneo hepatite C + melhor resposta ao PEG-IFN+ribavirina (antes dos DAAs). Primeiro biomarcador farmacogenômico em hepatologia

QUIMIOCINAS
CC / CXC / CX3C / XC
▶
Mecanismo Geral de Quimiotaxia ▶
Gradiente imobilizado: quimiocinas ligam heparan sulfato proteoglicanos (HSPGs) na superfície endotelial e MEC → gradiente estável de baixa (sangue) a alta (foco) concentração Quimiocina(+++) + HSPGs(—) → interação eletrostática (resíduos básicos Arg, Lys na quimiocina vs. grupos sulfato no HS) → gradiente imobilizado sem difusão livre
Receptor GPCR (7TM) → sinalização: Quimiocina → GPCR → Gαi:Gβγ dissociam → Gαi inibe adenilil ciclase → ↓AMPc → ↑PI3Kγ (via Gβγ) → PIP3 → Akt + Rac1/Cdc42 → Arp2/3 → actina-F ramificada (pseudópode frontal) → movimento direcional Gβγ também → PLCβ → IP3 → ↑Ca²⁺ → miosina → contração posterior da célula
Gradiente de sinalização intracelular: PIP3 se acumula no fronte do pseudópode; PTEN degrada PIP3 na parte posterior → assimetria → polarização célula → quimiotaxia direcional
Quimiocinas Clinicamente Relevantes ▶
CXCL8 (IL-8) / CXCR1+CXCR2: produzida por macrófagos/endotélio via NF-κB → quimioatrai neutrófilos (mais potente que todos os outros). CXCR2 → PI3K → actina → degranulação. ↑↑ em ARDS, sepse, NM. Montelucaste (anti-leucotrieno) não bloqueia CXCL8
CCL2 (MCP-1) / CCR2: endotélio ativado por LDL oxidado → CCL2 → CCR2 em monócitos → recrutamento ao subendotélio → diferenciação em macrófago → célula espumosa → aterosclerose. CCR2 KO em camundongos ApoE-/- → ↓aterosclerose drasticamente
CCL5 (RANTES) / CCR1+CCR3+CCR5: produzida por linfócitos T ativados/plaquetas/endotélio. CCR5 = co-receptor HIV-1 cepas R5-trópicas. CCR5-delta32 (deleção homozigota) → sem CCR5 → resistência natural ao HIV. Maraviroque = antagonista CCR5
CXCL12 (SDF-1) / CXCR4+CXCR7: CXCL12 = produzida constitutivamente por células estromais da medula → retém HSCs (célula-tronco hematopoiética) via CXCR4:CXCL12 → Gαi → PI3K → Rac → adesão VLA-4:VCAM-1. Plerixafor bloqueia CXCR4 → HSCs saem para sangue. CXCR4 = co-receptor HIV X4-trópico
CXCL9/10/11 / CXCR3: induzidas por IFN-γ → recrutam Th1 e CD8+ → feedback: Th1 produz IFN-γ → mais CXCL9/10 → mais recrutamento. CXCL10 = IP-10, biomarcador ativação Th1 (↑ em TB, hepatites virais, COVID-19 grave)
CCL19/CCL21 / CCR7: homeostáticas. Produzidas pelo estroma de linfonodos/baço. Células dendríticas maduras (que sofreram PAMP) → ↑CCR7 → migração para linfonodo → zona de células T → apresentação antigênica. Linfócitos T naïve também expressam CCR7 → homing a linfonodos

VIAS DE SINALIZAÇÃO E RECEPTORES
JAK-STAT / NF-κB / MAPK / SMAD
▶
Via JAK-STAT — Anatomia Molecular ▶
Estrutura das JAKs
4 JAKs: JAK1, JAK2, JAK3 (hematopoiética), TYK2. Cada JAK tem 7 domínios homólogos JH1-JH7: JH1 = domínio catalítico (quinase ativo, transfere PO₄ do ATP) JH2 = pseudokinase (regula JH1, inibe constitutivamente — mutação JH2 JAK2-V617F → mieloproliferativos) JH3-JH4 = domínio SH2-like JH5-JH7 = domínio FERM (ancoramento ao receptor)
JAK2-V617F: mutação no domínio pseudokinase → JH2 não consegue mais inibir JH1 → JAK2 constitutivamente ativa → STAT5 constitutivo → ↑eritropoiese independente de EPO → policitemia vera, trombocitemia essencial, mielofibrose
Mecanismo de Ativação Sequential
Passo a passo: 1. Citocina → receptor (monômero) → dimerização/oligomerização 2. JAKs pré-associadas às caudas do receptor aproximam-se 3. JAK-A transautofosforila JAK-B (e vice-versa) no loop de ativação (Y1007/Y1008 para JAK2) 4. JAKs ativadas fosforilam tirosinas no receptor (docking sites) 5. STATs recrutam via domínio SH2 (Src Homology 2) → pY-receptor 6. JAKs fosforilam STATs na tirosina conservada (Y701-STAT1, Y705-STAT3, Y694-STAT5) 7. pSTATs dissociam → dimerizam via SH2:pY reciproco 8. Dímero transloca ao núcleo → liga GAS ou ISRE 9. Recrutam coativadores (CBP/p300) → RNA polII → transcrição
Regulação Negativa
SOCS (Suppressor Of Cytokine Signaling): induzidos pelos próprios STATs (feedback negativo). SOCS3 → liga JAK via KIR (Kinase Inhibitory Region) + receptor → duplo bloqueio. SOCS1 → liga loop de ativação JAK → bloqueia substrato. SOCS1/3 → recrutam E3 ubiquitin ligase (Cullin5/Rbx2) → poliubiquitinação JAK → proteassoma
PIAS (Protein Inhibitor of Activated STAT): PIAS1/3 → SUMO E3 ligase → sumoilação STAT → inibe ligação ao DNA. PIAS-x/y → interagem com STAT1/4/5
SHP1/SHP2 (tyrosine phosphatases): removem grupos fosfato de STATs e do receptor → desativação. SHP1 deficiente em camundongos "motheaten" → inflamação sistêmica grave
Via NF-κB — O Hub da Inflamação ▶
Família NF-κB: p65 (RelA), RelB, c-Rel, p50 (NF-κB1), p52 (NF-κB2) → formam dímeros. O heterodímero p65:p50 é o mais comum NF-κB dimers → IκBα sequestra no citoplasma (mascara NLS=Nuclear Localization Signal) Sinal: IKKβ fosforila IκBα (S32/S36) → ubiquitina K48-Ub (Lys21/22) → SCF-βTrCP E3 ligase → 26S proteassoma → IκBα degradada → NF-κB livre → NLS exposto → importina α → núcleo
Via canônica (TLR/IL-1R/TNFR1): TRAF → TAK1 → IKK complexo (IKKα+IKKβ+NEMO) → pIκBα → degradação → p65:p50 → κB sites → TNF, IL-6, IL-8, IL-1, COX-2, iNOS, ICAM-1, MMP
Via não-canônica (BAFFR/CD40/LTβR): NIK → IKKα → clivagem p100→p52 → p52:RelB → genes desenvolvimento linfóide secundário
Glicocorticoides bloqueiam NF-κB: Transrepressão direta: GR:GC → núcleo → GR liga p65 diretamente → impede p65 de ligar κB sites (protein:protein) Transativação indireta: GR → ↑IκBα mRNA → mais IκBα → sequestra NF-κB recém-sintetizado
Via TGF-β / SMAD ▶
TGF-β: homodímero (12 kDa/subunidade), secretado em forma latente (LAP+TGF-β) → ativado por proteases (plasmina, MMP), integrina αvβ6, ou forças mecânicas → TGF-β ativo
Receptor: TGFβRII (constitutivamente ativo) → TGFβRI (ALK5) → SMAD2/3 fosforilados (C-terminal Ser-Ser-X-Ser) → associam SMAD4 → complexo R-SMAD:SMAD4 → núcleo → SBE (SMAD-binding element: 5'GTCT'3) → TGF-β target genes TGF-β → TGFβRII → recruta TGFβRI → TGFβRII fosforila TGFβRI (GS domain) → ativo → fosforila SMAD2(S465/S467)/SMAD3 → SMAD2/3:SMAD4 → núcleo → genes Treg (FOXP3), fibrose (Col1A, FN1, α-SMA), ↓IL-2
Efeitos opostos dependentes de contexto: célula epitelial normal → anti-proliferação + apoptose (tumor suppressor); célula tumoral avançada → EMT (Epithelial-Mesenchymal Transition) + metástase + imunossupressão (tumor promoter)
Inibidores em desenvolvimento: Galunisertibe (ALK5 inhibitor) em trials para hepatocarcinoma + glioblastoma; Fresolimumabe (anti-TGF-β) em tumores sólidos
JAK Inibidores — Farmacologia Molecular Detalhada ▶
Mecanismo geral: Competem com ATP (Ki nanomolar vs. [ATP]celular ~1–5 mM) pelo sítio catalítico (hinge region) da JAK → sem ATP → JAK não consegue fosforilar substrato → sem ativação STAT JAK-ATP sítio: Gly-rich loop (P-loop), C-helix, DFG motif (Asp-Phe-Gly), hinge region. Jakinibs → interagem com hinge via ligações H + hidrofóbicas → competem com adenina do ATP Seletividade: diferenças sutis nos "gatekeeper residues" (Thr vs. residuos menores) determinam especificidade
Tofacitinibe (JAK1/3 ≫ JAK2): JAK3 associada à γc → bloqueia IL-2, IL-4, IL-7, IL-9, IL-15, IL-21. Oral, meia-vida 3h, extensão de liberação disponível. Risco: ↑herpes zoster (JAK3 necessária para IL-15 → NK + memória T viral)
Baricitinibe (JAK1/2): bloqueia IL-6, IFN, EPO, GM-CSF. Também inibe AAK1 (AP2-associated kinase 1) → ↓endocitose clathrin-mediada → ↓entrada de vírus. Aprovado COVID-19 grave (+ dexametasona)
Upadacitinibe (JAK1 seletivo): ↓IL-6, IL-4/13, IFN. Maior potência que tofacitinibe em articulações. Alta biodisponibilidade oral. Extensão de liberação.
Ruxolitinibe (JAK1/2): mielofibrose (bloqueia JAK2-V617F mutante + JAK2 WT) + policitemia vera + DECH aguda grau 2-4. Efeito adverso: anemia/trombocitopenia (bloqueia EPO+TPO/JAK2)

HEMATOPOIESE — CITOCINAS QUE FAZEM SANGUE

▶
EPO — Eritropoietina e o Sensor de Hipóxia HIF ▶
Produção: 90% pelo rim (células intersticiais peritubulares tipo I do córtex), 10% fígado (fetal + adulto) SENSOR DE HIPÓXIA: O₂ normal → PHD (prolyl hydroxylase domains 1/2/3) + O₂ + Fe²⁺ + 2-oxoglutarato → hidroxila HIF-1α/HIF-2α (Pro402/Pro564) → VHL:ElonginB/C:Cullin2:Rbx1 E3 ligase → K48-poliUb → 26S proteassoma → HIF-α degrada Hipóxia → ↓O₂ → PHD inativo → HIF-α acumula → associa HIF-1β (ARNT) → HRE (5'RCGTG'3) → ↑EPO mRNA + VEGF, GLUT1, PDK1, etc.
Receptor EPO-R: homodímero JAK2:JAK2 pré-associados → EPO → dimerização forçada → transautofosforilação JAK2 → pY-EPO-R → STAT5 → pSTAT5 → Bcl-xL (anti-apoptose eritroblastos) + GATA-1 → diferenciação BFU-E → CFU-E → eritroblastos → reticulócitos → eritrócitos (5–7 dias)

G-CSF / GM-CSF — Neutrófilos e Mobilização de CTH ▶
G-CSF: 174 aa, 18–22 kDa. Receptor G-CSFR (CD114) → homodimeriza → JAK2 → STAT3 → ↑diferenciação de progenitores mielóides → CFU-G → neutrófilos maduros. Também ↑elastase (ELANE) → libera HSCs da medula (clivagem CXCL12 e VCAM-1) G-CSF → G-CSFR:G-CSFR → JAK1:JAK2 → pSTAT3 + pSTAT5 → C/EBPε/α → genes granulocíticos (MPO, elastase, lactoferrina) → maturação + liberação ao sangue
Filgrastim: G-CSF recombinante humana não-glicosilada (E. coli). Meia-vida 3,5h. SC diário
Pegfilgrastim: filgrastim+PEG 20kDa → meia-vida 30–40h → 1 dose/ciclo quimio → neutropenia febril pós-QT
GM-CSF (Sargramostim): receptor βc (compartilhado IL-3R, IL-5R) → JAK2 → STAT5 → diferenciação neutrófilos + monócitos + DCs. Usado pós-HSCT + quimioterapia (recuperação multilinear)
TPO / IL-7 — Plaquetas e Linfócitos ▶
Trombopoietina (TPO): 332 aa, ~95 kDa. Produzida constitutivamente pelo fígado (THPO gene → mRNA) → receptor MPL (c-Mpl) → JAK2 → STAT5 → GATA-1 + NF-E2 → megacariocitopoiese → projeções protoplaquetar → plaquetas. TPO sérica regula-se por absorção pelas plaquetas (plaquetas↑ → absorvem mais TPO → menos livre → megacariócitos↓ → plaquetas↓: feedback) TPO → MPL:MPL → JAK2:TYK2 → pY599/626-MPL → STAT5 + STAT3 + MAPK → GATA-1:FOG1:NF-E2 → CD41 (GPIIb), CD61 (GPIIIa), VWF → protoplaquetas → plaquetas 2–10 µm
Agonistas do receptor TPO (TPO-RAs): eltrombopague (molécula pequena oral, interage com domínio TM do MPL), romiplostim (peptibody = Fc+péptido mimético TPO), avatrombopague (oral) → ↑megacariocitopoiese → PTI, anemia aplástica, trombocitopenia por hepatite C
IL-7: 152 aa. Produzida por células estromais de timo/linfonodos/medula. Receptor IL-7Rα+γc → JAK1+JAK3 → STAT5 → ↑Bcl-2 → sobrevida de linfócitos T e B naïve + células de memória. Essencial para desenvolvimento de células T no timo (↑RAG1/2 → rearranjo TCR). Deficiência IL-7Rα → linfopenia T grave (SCID T-B+NK+)

Receptores Chamariz (Decoy Receptors) ▶
IL-1Ra (Antagonista do Receptor de IL-1): liga IL-1R1 com mesma afinidade que IL-1α/β (Kd ~200 pM) mas NÃO recruta IL-1RAcP → sem sinalização. Produção: macrófagos M2 (IL-4/IL-13 induzem IL1RA mRNA). A razão IL-1/IL-1Ra determina o grau de inflamação. Em sepse grave, razão IL-1/IL-1Ra favorece IL-1 → inflamação
IL-1R2: receptor membrana sem domínio TIR → liga IL-1β (preferencial) sem sinalizar → "sumidouro". Regulado positivamente por IL-4, dexametasona
sTNFR1/sTNFR2: shedding via ADAM17/TACE → receptores solúveis → capturam TNF antes de atingir receptor celular → tamponamento. Base do etanercepte (TNFR2-Fc fusion)
IL-18BP (IL-18 Binding Protein): proteína secretada (não é receptor de membrana), Kd ~400 pM (maior afinidade que IL-18Rα). Induzida por IFN-γ (feedback: IFN-γ via IL-18 → induza IL-18BP que bloqueia IL-18 → limita produção de IFN-γ)
Eixo HPA — Cortisol como Anti-Inflamatório ▶
Loop completo: IL-1β/IL-6/TNF-α → núcleo paraventricular hipotálamo → CRH (41 aa) → hipófise anterior: CRH-R1 (GPCR) → AMPc → PKA → POMC → ACTH (39 aa) → córtex adrenal zona fasciculada → MC2R (GPCR) → AMPc → StAR → colesterol → pregnenolona → cortisol → cortisol → GR-α (receptor intracelular, família NR) → núcleo → anti-inflamação
Mecanismo molecular do cortisol (transrepressão): GR:cortisol → GR transloca (Hsp90 dissocia) → nucleus Transrepressão direta: GR(DBD) liga p65(Rel homology domain) → bloqueia p65:κB Transrepressão via AP-1: GR liga c-Jun:c-Fos → bloqueia AP-1:TRE Transativação: GR:GRE (glucocorticoid response elements) → ↑GILZ(glucocorticoid-induced leucine zipper, inibe NF-κB+AP-1) + ↑IκBα + ↑MKP-1(inativa MAPK) + ↑ANXA1(lipocortina, inibe PLA2→↓AA→↓PGs)
Resistência ao glicocorticoide: GR-β (isoforma sem ligação) age como dominante negativo sobre GR-α → expressa em células de doenças inflamatórias refratárias → explica por que alguns pacientes com asma/AR não respondem a corticoide. IL-2 e IL-4 ↑GR-β
Tregs — O Braço Supressor Linfocitário ▶
FoxP3: fator de transcrição mestre das Tregs. Se liga a NFAT → reprograma ativação em supressão. ↑CD25, ↑CTLA-4, ↓IL-2 (competição pelo IL-2 ambiental)
Mecanismos de supressão das Tregs: 1. Contacto-dependente: CTLA-4 em Treg → CD80/86 em DC → transendocitose de B7 → DC sem coestimulação → células T não ativadas 2. IL-10 secretada → macrófagos tolerogênicos → ↓APCs 3. TGF-β secretado (e membrana-associado) → SMAD2/3 em células T efetoras → ↓proliferação 4. IL-35 → STAT1:STAT4 → Tr35 (induz novas Tregs) 5. Consumo de IL-2 (CD25 alta expressão → "rouba" IL-2 do microambiente → células T efetoras ficam sem sinal de sobrevida)
Instabilidade de Tregs em inflamação: IL-6 + IL-1β inibem FoxP3 → Treg "plástica" pode converter-se em Th17 ex-Treg (mantém CD25 mas expressa IL-17 e RORγt) → piora autoimunidade

DOENÇAS — REDES DE CITOCINAS DESEQUILIBRADAS
Sepse / COVID / AR / DII / Psoríase / Câncer / SAM
▶
Sepse — Tempestade Pró-inflamatória + Paralisia CARS ▶
Fase SIRS (primeiras horas): LPS → TLR4 → TNF-α (pico 1–2h) → IL-1β (2–4h) → IL-6 (4–6h) → IL-8, MCP-1, PAF, prostaglandinas, NO → choque distributivo + CID + ARDS
Fase CARS (48–72h+): ↑IL-10, ↑IL-1Ra, ↑sTNFR, ↑TGF-β → ↓HLA-DR em monócitos (<30% = paralisia imune) → infecções secundárias (CMV, EBV, fungos, gram-negativos resistentes). Esta fase é causa de mortalidade tardia em UTI
Fenótipos de sepse (endotipos): SRS1 (Sepsis Response Signature 1): ↓expressão genes imune adaptativos, ↑TGF-β, endotipo imunossuprimido → pior mortalidade SRS2: inflamação mais preservada → melhor prognóstico Implicação: tratar SIRS com anti-citocinas + tratar CARS com imunoestimuladores (GM-CSF, IFN-γ em paralisia imune) — medicina de precisão
Biomarcadores: IL-6 >1000 pg/mL, PCR >150 mg/L, PCT >2 ng/mL = fase SIRS. HLA-DR <30% em monócitos = CARS. IL-10 >100 pg/mL = imunossupressão
COVID-19 Grave — Fisiopatologia Molecular ▶
Evasão de IFN tipo I: NSP1 bloqueia tradução de mRNA celular (incluindo ISGs); NSP3 deubiquitinase remove ubiquitina de IRF3 (impede ativação); ORF6 bloqueia importação nuclear via RanGAP1; NSP12 metiltransferase mimética mascara RNA como self SARS-CoV-2 estratégias anti-IFN: 1. NSP1 → 40S ribossoma → bloqueia mRNAs celulares (incluindo IFN mRNA) 2. NSP3 (PLpro) → deubiquitina IRF3/STING → inativa 3. ORF6 → liga RanGAP1 → STAT1 não entra no núcleo 4. ORF9b → MAVS + TOM70 → mitocôndria não sinaliza 5. N proteín → faz condensados líquidos com MAVS → sequestra
Tempestade de citocinas pulmonar: vírus replica sem controle → dano maciço → DAMPs → macrófagos alveolares ativados (MoAM = monocyte-derived alveolar macrophages) → ↑↑IL-6, ↑↑CXCL8/10, ↑TNF-α → NETs (Neutrophil Extracellular Traps) → trombose microvascular + dano epitelial
Imunossupressão paradoxal: linfopenia de células T (apoptose por IL-6 + migração para pulmão + exaustão por PD-1 constitutivo) + ↑IL-10 → susceptibilidade a infecções bacterianas secundárias
SAM / LHH — Hiperativação Macrofágica ▶
Fisiopatologia central: defeito em degranulação de células NK/CTL (perforina, granzimas → RAB27A, LYST, PRF1, STXBP2 mutações na LHH primária) → incapacidade de matar APCs → APC persiste → Th1 persiste → IFN-γ imparável → macrófago ativado constitutivamente → hemofagocitose + liberação massiva de citocinas Deficiência perforina/granzima → NK não mata DC infectada → DC persiste → Th1+NK produzem IFN-γ cronicamente → macrófago M1 excessivo → IL-18, CXCL9, ferritina, IL-6, IL-10 → tempestade + hemofagocitose
Citocinas assinatura SAM: IL-18 >10.000 pg/mL (mais específico), CXCL9 >2000 pg/mL (induzido por IFN-γ em macrófagos), ferritina >10.000 ng/mL, IL-6 >2000 pg/mL
Tratamento direcionado: Emapalumabe (anti-IFN-γ) → aprovado LHH primária refratária. Anakinra (anti-IL-1R) → SAM secundária/Still. Ruxolitinibe (JAK1/2) → bloqueia IFN-γ e citocinas pró-inflamatórias. DEX+etoposídeo (HLH-2004 protocol)
Câncer — Microambiente Tumoral Imunossupressor ▶
Citocinas imunossupressoras do TME: Células tumorais → TGF-β → Tregs + ↓NK + ↓CD8+ effector + EMT → IL-10 → DCs tolerogênicas → MDSC diferenciação → VEGF → DCs imaturas (VEGFR2) + ↑MDSC recrutamento → IDO1 (induzido por IFN-γ + TNF) → ↓Trp → GCN2 em T → T anérgico + ↑Tregs → CCL2/CCL22 → TAMs M2 (IL-10, TGF-β, ↑IDO, ↑arginase) + Tregs
Eixo PD-1/PD-L1: IFN-γ (produzido por TILs) → tumor → JAK1/2 → STAT1 → IRF1 → PD-L1 (CD274) ↑ → PD-L1:PD-1 (em células T) → SHP2 → desfosforila ZAP70/CD3ζ → ↓TCR signaling → exaustão T. Anti-PD-1/PD-L1 → reativa TCR → resposta antitumoral. Paradoxo: IFN-γ ativaria tumor E desativa T → tumor usa IFN-γ como escudo
Resistência primária a anti-PD-1: ↓JAK1/JAK2 (mutações) → sem IFN-γ signaling → sem STAT1 → sem ↑MHC I → CD8+ não reconhecem tumor (invisibilidade). ↓B2M → sem MHC I. ↑TGF-β, ↑IL-10, ↑IDO → alternativas imunossupressoras que bypass PD-L1

Rastreamento Pré-Biológico (Checklist) ▶
TB latente: IGRA (QFT-Plus) ou PPD → se positivo → isoniazida 9 meses (começar 4 semanas antes do biológico). RXT tórax obrigatória
HBV: HBsAg + Anti-HBc total + Anti-HBs → se HBsAg+ ou Anti-HBc+ isolado → CV-HBV + profilaxia entecavir/tenofovir (risco reativação, especialmente rituximabe + anti-TNF)
HIV, HCV: sorologia. HCV se positivo → CV + tratar (DAAs) antes se possível
Vacinas (antes do biológico — vivas contraindicadas após): influenza, pneumococo, HBV, herpes zoster (Shingrix=inativada), dT/dTpa, HPV se indicado
Neoplasia: rastreamento câncer de pele (anti-TNF ↑risco CPCNM), hemograma com diferencial
Seleção do Biológico por Perfil de Citocinas ▶
Asma grave: Eosinófilos >300/µL + IL-5 dominante → anti-IL-5 (mepolizumabe/reslizumabe/benralizumabe) FeNO >25 ppb + atopia + IL-4/13 → dupilumabe (anti-IL-4Rα) Alergia + IgE 30–1500 → omalizumabe (anti-IgE) Misto → dupilumabe (bloqueia IL-4/13 → ↓IgE + eosinófilos)
Psoríase/EspA: Psoríase grave + artrite periférica → anti-IL-17A (secuquinumabe) ou anti-IL-23 (rizankizumabe) Espondilite axial → anti-IL-17A (secuquinumabe/ixequizumabe) OU anti-TNF Crohn associado → EVITAR anti-IL-17 → preferir anti-TNF ou anti-IL-12/23 (ustekinumabe)
AR: Ativa após falha MTX → anti-TNF (adalimumabe 1ª opção) OU tocilizumabe (preferível se marcadores sistêmicos↑: febre, anemia, PCR muito alta = IL-6 dominante) OU abatacepte (se TB latente prévia, risco infecção) Se falha anti-TNF → trocar mecanismo: anti-IL-6R OU JAKinib OU rituximabe (anti-CD20) Gestação → certolizumabe pegol (sem FcRn → não cruza placenta)
COVID-19 grave (O₂ suplementar + IL-6 ↑): dexametasona + tocilizumabe → redução mortalidade 35%+13% respectivamente (RECOVERY trial)
Monitoramento de Eficácia e Toxicidade ▶
Anti-IL-6R (tocilizumabe/sarilumabe): EFICÁCIA: PCR normaliza em 48–72h (PCR = produção hepática totalmente dependente de IL-6). NÃO usar IL-6 sérica (paradoxalmente sobe após tocilizumabe) TOXICIDADE: neutropenia (IL-6 necessária para sobrevida neutrófilos: G-CSFR usa JAK1/JAK2 indiretamente via IL-6/STAT3) + ↑transaminases (hepatotoxicidade em 5–10%) + perfuração GI (IL-6 protege mucosa GI) + hiperlipidemia (IL-6 suprime LDL → sem IL-6 → LDL↑)
JAK inibidores: EFICÁCIA: PCR + DAS28 (AR) ou PASI (psoríase) ou HBI/Mayo (DII) a cada 12 semanas TOXICIDADE: herpes zoster (↑2–3× vs DMARD conv.) → vacinar Shingrix antes se possível; infecções bacterianas; anemia/neutropenia (dose-dependente, mais com JAK2); lipídeos↑ (LDL, HDL); risco cardiovascular (FDA warning tofacitinibe vs adalimumabe no ORAL Surveillance); trombose venosa (JAK1/3)
Anti-TNF (monitoramento): ADA (anti-drug antibodies): titular nível sérico do biológico (trough level) + ADA a cada 6–12 meses Nivel infliximabe >3 µg/mL + ADA negativos = remissão biológica Nível baixo + ADA+ → trocar para outro mecanismo (não outro anti-TNF) Nível baixo + ADA- → aumentar dose ou frequência
