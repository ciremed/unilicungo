Inflamação Aguda
⚡
Definição & Causas
▼
Definição
Resposta vascular e celular imediata a agentes lesivos. Duração: horas–dias. Células predominantes: neutrófilos.
Etimologia
Latim: inflammare = "colocar em chamas". Descrita por Celsus (séc. I d.C.).
Causas
Infecções microbianas · Necrose tecidual · Corpos estranhos · Reações imunes · Físicas (trauma, queimadura) · Químicas (ácidos, toxinas)
3 Etapas
1. Alterações vasculares → 2. Eventos celulares → 3. Mediadores químicos
🫀
Alterações Vasculares
▼
1. Vasoconstrição transitória
Segundos · SNS + Endotelina-1 → ET_A → Gq → IP₃ → ↑Ca²⁺ → contração CML
2. Vasodilatação arteriolar
Histamina (H₁), NO (eNOS/iNOS), PGE₂, Bradicinina → RUBOR + CALOR
L-arginina + O₂ → (NOS) → Citrulina + NO•
3. ↑ Permeabilidade vascular
Contração endotelial (Histamina, BK, LTs) → abertura das tight junctions nas vênulas pós-capilares · Lesão direta · Transcitose (VEGF) → TUMOR (edema)
4. Estase vascular
↑ Viscosidade → lentificação → marginação leucocitária → base para o recrutamento celular
📐
Lei de Starling — Física do Edema
▼
Jv = Kf × [(Pc − Pi) − σ(πc − πi)] Jv = fluxo líquido de fluido Kf = coeficiente de filtração hidráulica Pc = pressão hidrostática capilar Pi = pressão hidrostática intersticial σ = coeficiente de reflexão proteica (0–1) πc = pressão oncótica capilar (~25 mmHg) πi = pressão oncótica intersticial (~3 mmHg)
⚠ Na inflamação ↑ permeabilidade → σ ≈ 0 · proteínas extravasam → ↑ πi · vasodilatação → ↑ Pc → edema maciço (exsudato)
TipoProteínasCélulasExemplo
Transudato< 3 g/dLRarasICC, cirrose
Exsudato> 3 g/dLMuitos leucócitosPneumonia, peritonite

Desfechos da Inflamação Aguda
▼
✅ Resolução completa (ideal)
Mediadores inativados · Neutrófilos em apoptose (efferocytosis por macrófagos) · Drenagem linfática · Regeneração tecidual
Mediadores pró-resolução: Lipoxinas, Resolvinas (EPA/DHA), Protectinas, Maresinas
🔴 Fibrose/Cicatriz
Destruição tecidual extensa → fibroblastos/miofibroblastos → colágeno I e III → cicatriz fibrosa (ex: infarto do miocárdio)
🔄 Progressão para crônica
Agente persiste → macrófagos + linfócitos substituem neutrófilos → inflamação crônica
💀 Abscesso
Bactérias piogênicas (S. aureus) → coleção localizada de pus → cápsula fibrosa
🌡️
Febre — Fisiopatologia
▼
Pirógenos exógenos (LPS, peptidoglicano, vírus) ↓ TLR4 / NLRs Macrófagos → TNF-α, IL-1β, IL-6 (pirógenos endógenos) ↓ Hipotálamo (área pré-óptica) Células endoteliais → COX-2 → PGE₂ ↓ Receptor EP₃ → ↓ AMPc → ↑ set point Vasoconstrição cutânea + calafrios → FEBRE
⚠ Síndrome de Reye Nunca usar AAS em crianças <12 anos com infecções virais (varicela, influenza) → risco de encefalopatia hepática aguda fatal.

Eventos Celulares — Recrutamento Leucocitário
🎯
A Cascata "Rolling → Adhesion → Transmigration"
▼
1. MARGINALIZAÇÃO — leucócitos se aproximam do endotélio (estase + fluxo laminar) 2. ROLAMENTO — Selectinas (P, E, L) ligam-se a PSGL-1 / Sialil-Lewis X 3. ADESÃO FIRME — Integrinas (LFA-1/Mac-1) ligam ICAM-1/VCAM-1 (inside-out signaling via quimiocinas) 4. DIAPEDESE — PECAM-1 (CD31), CD99, JAMs; paracelular (90%) ou transcelular 5. QUIMIOTAXIA — gradiente de IL-8, C5a, LTB4, fMLP → PI3K → Rac1 → actina → pseudópodos

Fagocitose & Arsenal do Neutrófilo
▼
Opsoninas
IgG (→ FcγR) · C3b (→ CR1, CR3) · MBL · PCR — revestem o patógeno para facilitar fagocitose
Burst Oxidativo (O₂-dependente)
NADPH + 2O₂ → (NADPH oxidase) → O₂•⁻ → H₂O₂ → (MPO) → HOCl
HOCl = "água sanitária biológica" = principal microbicida
O₂-independente
Defensinas (poros na membrana) · Lisozima (cliva peptidoglicano gram+) · Elastase · Lactoferrina (sequestra Fe²⁺) · BPI (contra gram−) · pH ácido
NETs (Neutrophil Extracellular Traps)
Cromatina + histonas + enzimas → rede extracelular captura bactérias/fungos. NETs excessivos → trombose, ARDS, LES
⚠ Doença Granulomatosa Crônica (CGD) Mutação gp91phox (NADPH oxidase, gene CYBB, ligado ao X) → sem burst oxidativo → infecções por catalase-positivos (S. aureus, Aspergillus). Diagnóstico: teste DHR ou NBT.

Histamina & Serotonina
▼
Histamina
Origem: Mastócitos, basófilos, plaquetas
Síntese: L-histidina → (Hdc) → Histamina
H₁: vasodilatação, ↑ permeabilidade, prurido, broncoespasmo
H₂: ↑ secreção ácida gástrica
Estímulos para degranulação
Trauma físico · IgE + alérgeno · C3a, C5a (anafilatoxinas) · IL-1, IL-8 · Substância P
💊 Anti-H₁ 2ª geração Loratadina, cetirizina, fexofenadina — não atravessam BHE, menor sedação. Indicados: rinite alérgica, urticária.

Sistema das Cininas & Óxido Nítrico
▼
Cascata das Cininas
Fator XII (Hageman) → Calicreína → Bradicinina (9aa)
Receptor B₂ → ↑ NO, PGI₂ → vasodilatação, ↑ permeabilidade, DOR, broncoespasmo
Meia-vida: 15–30s (degradada pela ECA)
Óxido Nítrico (NO)
L-arginina + O₂ → (eNOS/iNOS) → Citrulina + NO•
NO ativa guanilato ciclase → ↑ GMPc → vasodilatação (RUBOR/CALOR)
iNOS induzida em macrófagos → NO bactericida
⚠ IECAs e Bradicinina Captopril, enalapril inibem a ECA → ↑ bradicinina → tosse seca (10–15%) e angioedema (grave!). Sartans não inibem ECA → muito menos tosse/angioedema.

Inflamação Granulomatosa
🏗️
Formação do Granuloma
▼
1. Agente persistente (M. tb, fungo, corpo estranho) não é eliminado 2. Macrófagos ativados cronicamente por IFN-γ (de Th1) 3. Macrófagos → CÉLULAS EPITELIOIDES (citoplasma eosinofílico abundante) 4. Fusão de células epitelioides → CÉLULAS GIGANTES MULTINUCLEADAS 5. Linfócitos T CD4⁺ circundam: "coroa linfocitária" 6. Fibroblastos na periferia → cápsula fibrosa 7. Centro: necrose caseosa (TB) ou ausente (sarcoidose)
Citocinas chave
IFN-γ (Th1/NK) → células epitelioides · TNF-α → mantém integridade · IL-12 (MΦ) → Th1 → IFN-γ (loop positivo)
⚠ Anti-TNF e TB TNF-α é essencial para manter granulomas. Anti-TNF (etanercepte, adalimumabe) → granuloma desfaz → TB latente reativa → TB ativa disseminada. SEMPRE rastrear com QuantiFERON-TB Gold / PPD antes de iniciar.

Leucocitose & Desvio à Esquerda
▼
Mecanismo
IL-1β, TNF-α, IL-6, G-CSF → medula → ↑ granulopoese + mobilização de pool marginal
Leucocitose típica: 15.000–20.000/µL (normal 4–10k)
Padrões
Neutrofilia + desvio esquerda: infecção bacteriana/sepse
Linfocitose: viral (mono, CMV, rubéola)
Eosinofilia: parasitoses, alergias
Leucopenia: sepse grave, HIV, influenza (consumo)
Desvio à esquerda
Aparecimento de formas imaturas no sangue: bastões > metamielócitos > mielócitos. Indica demanda medular intensa.

Sepse — Inflamação Sistêmica Desregulada
▼
Definição (Sepsis-3, 2016)
Disfunção orgânica potencialmente fatal causada por resposta desregulada do hospedeiro a uma infecção. SOFA ↑ ≥ 2 pontos.
PAMPs (LPS, peptidoglicano) → TLR4/NLRs ↓ MΦ, monócitos ativados massivamente ↓ ↑↑ TNF-α, IL-1β, IL-6, IL-8, PAF, C5a ↓ iNOS → NO massivo → vasodilatação generalizada Fator Tecidual → CID → trombose microvascular TNF-α → disfunção miocárdica ↓ CHOQUE SÉPTICO: PAM <65 + vasopressor + lactato >2mmol/L
💊 Bundle Hora 1 (Surviving Sepsis Campaign) 1. Hemocultura (2 pares) · 2. ATB amplo espectro em <1h · 3. Lactato sérico · 4. 30 mL/kg cristaloide (se hipotensão ou lactato ≥4) · 5. Norepinefrina se PAM <65

Calculadora — Lei de Starling
📐
Jv = Kf × [(Pc − Pi) − σ(πc − πi)]
▼

Calcule o fluxo líquido de fluido no capilar. Valores positivos = filtração (edema). Ajuste os parâmetros para simular condições normais vs. inflamatórias.

Valores normais de referência
Extremidade arterial: Pc ≈ 35 mmHg · Extremidade venosa: Pc ≈ 15 mmHg · πc ≈ 25 mmHg · σ ≈ 0,9 · πi ≈ 3 mmHg · Pi ≈ −2 mmHg
Na inflamação
σ cai para ~0,2 (proteínas passam livremente) · πi sobe (proteínas no interstício) · Pc aumenta (vasodilatação) → Jv muito positivo = EDEMA INFLAMATÓRIO
